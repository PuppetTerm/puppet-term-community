# PuppetTerm Community

The public place for bug reports, feature requests and questions about
**PuppetTerm** and its **WebApplets**.

PuppetTerm is a native macOS workspace for AI coding agents, terminals and
WebApplets. This repository hosts community reports and support information;
application development is maintained separately.

**English and German are welcome. Beiträge auf Deutsch sind willkommen.**

## Open an issue

| What would you like to do? | Start here |
| --- | --- |
| Report something that is not working | [Bug report](https://github.com/PuppetTerm/puppet-term-community/issues/new?template=01-bug-report.yml) |
| Suggest an improvement or a new applet | [Feature or applet request](https://github.com/PuppetTerm/puppet-term-community/issues/new?template=02-feature-request.yml) |
| Ask a question or get help | [Question or help](https://github.com/PuppetTerm/puppet-term-community/issues/new?template=03-question.yml) |

Search [existing issues](https://github.com/PuppetTerm/puppet-term-community/issues)
first. If your topic is already covered, add useful details to that issue or react
with a thumbs-up. For a new report, include the product and version involved.
Applet names are free text, so newly released applets are welcome too.

## Get PuppetTerm

- [Official website](https://puppet-term.app/)
- [Download the latest macOS release](https://mirror.puppet-term.app/latest.dmg)
- [Browse WebApplets](https://puppet-term.app/applets)

Install WebApplets through **Settings → WebApplets → Online catalog** in PuppetTerm.

## Sharing diagnostics

For a bug report, a diagnostic report can help. In PuppetTerm, open
**Help → Diagnostics …**, choose **Start Diagnostics**, then **Export Report …**.
Attaching a report is optional. Review text, screenshots and files before posting:
issues and attachments in this repository are public. Remove credentials, API
tokens and private project or customer information.

For a security-sensitive report or private information, use the
[PuppetTerm contact form](https://puppet-term.app/contact.php).

See [contributing](CONTRIBUTING.md) for reporting tips.
