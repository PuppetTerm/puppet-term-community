# Contributing to PuppetTerm Community

English and German reports are welcome. Choose the form that best matches your
topic: [bug, feature request or question](https://github.com/PuppetTerm/puppet-term-community/issues/new/choose).

## Bug reports

- Search for an existing report before opening a new one.
- Describe one problem per issue and give the shortest steps that reproduce it.
- Include the PuppetTerm and macOS versions. For an applet issue, add the applet's
  name and version from **Settings → WebApplets → Local**.
- Describe what you expected and what actually happened.
- If relevant, include the AI coding tool's name and version.
- Screenshots and exported diagnostics are optional. Review them before uploading.

If the app will not open, report the downloaded version or write "unknown" and
explain where startup stops. You can add missing details later in a comment.

## Ideas and questions

Explain the task you are trying to complete and why the current behavior gets in
the way. A concrete example is useful. New applet ideas belong in the feature
request form. For help, describe what you have already tried.

## Public and private information

Reports and attachments here are public. Remove secrets, personal information
and private project or customer data. For a security-sensitive report, use the
[PuppetTerm contact form](https://puppet-term.app/contact.php).

Keep discussions respectful and focused on the reported problem. Documentation
improvements to this community repository are welcome as pull requests.
